# 신호 선정 기준

최종 신호는 HIGH2Y_BASE(504거래일·최소 403가격)와 LOWVOL60(60개 인접 유효 수익률)이다. 모멘텀 선정 자료는 momentum/의 final_candidates.csv·설정·메타데이터·SPA 표, 저변동성 선정 자료는 lowvol/의 지표·설정·메타데이터에 있다.

모멘텀 선정 기준은 MCS90 포함·연간 회전율 3 이하·월간 또는 offset 평균 재선정 후보 중 Sharpe 순위다. 검증 도구가 선택 결과를 확인한다. 선정 자료는 현재 최종 장부와 평가 조건이 달라 최종 성과로 혼용하지 않는다. 여러 후보를 관찰한 선택이므로 사전 고정 표본외 우위의 증거로 해석하지 않는다. 이 묶음은 선정 결과의 근거이며 전체 후보의 SPA/MCS 재추정을 위한 일별 자료를 포함하지 않는다.
